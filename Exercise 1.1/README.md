My Python Project: Course Work Repository

This repository serves as a portfolio and tracker for my progress through the Python course. It contains separate folders for each exercise, housing all required deliverables, scripts, and documentation.

Structure

Each exercise is organized into a dedicated folder (e.g., Exercise 1.1, Exercise 1.2, etc.).

Exercise 1.1: Virtual Environments and Basic Scripting

Deliverables:

Exercise 1.1/add.py: A Python script that accepts two integer inputs from the user and prints their sum.

Exercise 1.1/requirements.txt: A file listing the ipython package and its dependencies, used to ensure environment portability.

Exercise 1.1/learning_journal.md: Documentation of learning goals and concepts covered in this exercise.

Concepts Covered:

Setting up and activating isolated Python virtual environments (venv).

Installing packages using pip (specifically ipython).

Using the pip freeze > requirements.txt command for environment portability.

Creating a basic Python script with user input (input() and int()) and output (print()).
